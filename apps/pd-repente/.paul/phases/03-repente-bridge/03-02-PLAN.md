## AC-1: PdParser detects all three response formats
```gherkin
Given a response string from the LLM

When response contains "#N canvas" anywhere in first 200 chars
Then PdParser::parse returns { type: PD_PATCH, content: full response }

When response contains "pds." or starts with "{"
Then PdParser::parse returns { type: LUA_BLOCK, content: response }

When response starts with "/pds" (after trimming whitespace/markdown fences)
Then PdParser::parse returns { type: PDS_COMMANDS, content: response }

When response matches none of the above
Then PdParser::parse returns { type: LUA_BLOCK, content: response }
  (fallback: try as Lua — least destructive failure mode)
```

## AC-2: Bridge executes parsed response end-to-end
```gherkin
Given Bridge constructed with valid RepenteClient::Config and a PluginEditor*

When Bridge::send(prompt) is called
Then RepenteClient::send fires
And on response:
  PD_PATCH  → tabComponent.openPatch(content) opens new tab on message thread
  LUA_BLOCK → PromptInput::executeCommand("{" + content + "}") runs on message thread
  PDS_COMMANDS → each line CommandParser::parse → Executor::submit on message thread
And console logs the LLM response type and result

When RepenteClient returns "error: ..."
Then Bridge logs the error to console and does NOT touch canvas
```

## AC-3: PromptInput free-text routes to Bridge
```gherkin
Given plugdata is running with an active canvas

When user types any text that is NOT a /command, NOT sugar syntax,
     NOT a { lua block }
Then PromptInput calls Bridge::send(text)
And console shows "repente: thinking..." immediately (user feedback)
And when response arrives, canvas is modified (or error shown)

When Bridge is null (not yet configured)
Then PromptInput shows "repente: not configured (use /help llm)" instead of crash
```

    enum class ResponseType { PD_PATCH, LUA_BLOCK, PDS_COMMANDS };

        ResponseType  type;
        juce::String  content; // stripped of markdown fences if any
    };

    class PdParser {
    public:
        // Detects format and strips markdown code fences (```pd ... ``` etc.).
        // Never throws — returns LUA_BLOCK as fallback.
        static ParsedResponse parse(juce::String const& response);

    private:
        static juce::String stripFences(juce::String const& s);
    };

    } // namespace RepentePd
    ```

    ### PdParser.cpp

    Detection order (check in this order to avoid false positives):

    1. **Strip markdown fences first** (`stripFences`):
       - Remove leading/trailing ` ``` `, ` ```pd `, ` ```lua `, ` ```puredata `
         if the entire response is wrapped in them.
       - Pattern: if trimmed string starts with ` ``` ` (with optional language tag on same line)
         and ends with ` ``` `, strip first and last line.

    2. **PD_PATCH detection** — check stripped content:
       - `content.contains("#N canvas")` → PD_PATCH
       - Also accept `content.contains("#N CANVAS")` (case-insensitive variant)

    3. **PDS_COMMANDS detection** — check stripped content:
       - First non-empty line starts with `/pds` → PDS_COMMANDS

    4. **LUA_BLOCK** — everything else (including `pds.` calls, raw Lua, free text
       that falls through to LLM next time). This is the safest fallback: wrapping
       arbitrary text in `{ }` produces a Lua error, which is logged but harmless.

    ### stripFences implementation:
    ```cpp
    juce::String PdParser::stripFences(juce::String const& s)
    {
        auto t = s.trim();
        if (!t.startsWith("```")) return t;
        int firstNewline = t.indexOf("\n");
        if (firstNewline < 0) return t;
        // Drop first line (``` or ```pd etc.) and trailing ```
        auto body = t.substring(firstNewline + 1).trimEnd();
        if (body.endsWith("```"))
            body = body.dropLastCharacters(3).trimEnd();
        return body;
    }
    ```

    ### Full parse():
    ```cpp
    ParsedResponse PdParser::parse(juce::String const& response)
    {
        juce::String content = stripFences(response);

        if (content.containsIgnoreCase("#N canvas"))
            return { ResponseType::PD_PATCH, content };

        // First non-empty line check for /pds
        for (auto const& line : juce::StringArray::fromLines(content)) {
            auto trimmed = line.trim();
            if (trimmed.isEmpty()) continue;
            if (trimmed.startsWith("/pds"))
                return { ResponseType::PDS_COMMANDS, content };
            break; // only check first non-empty line
        }

        return { ResponseType::LUA_BLOCK, content };
    }
    ```

    ### Bridge.h

    ```cpp
    #pragma once
    #include "RepenteClient.h"
    #include "PdParser.h"
    #include <functional>

    class PluginEditor;

    namespace RepentePd {

    // Orchestrates: prompt → RepenteClient → PdParser → execution path.
    // All public methods must be called from the message thread.
    class Bridge {
    public:
        explicit Bridge(PluginEditor* editor);
        ~Bridge() = default;

        // Fire-and-forget. Logs "thinking..." to console immediately.
        // Fires onDone(success) on message thread when complete.
        void send(juce::String const& prompt,
                  std::function<void(bool)> onDone = {});

        void setConfig(RepenteClient::Config cfg);
        [[nodiscard]] RepenteClient::Config const& getConfig() const;
        [[nodiscard]] bool isBusy() const;

    private:
        void execute(ParsedResponse const& parsed);

        PluginEditor*  editor;
        RepenteClient  client;

        JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR(Bridge)
    };

    } // namespace RepentePd
    ```

    ### Bridge.cpp

    ```cpp
    #include "Utility/Config.h"
    #include "Bridge.h"
    #include "RepentePd/Commands/CommandParser.h"
    #include "PluginEditor.h"

    namespace RepentePd {

    Bridge::Bridge(PluginEditor* ed) : editor(ed) {}

    void Bridge::setConfig(RepenteClient::Config cfg) { client.setConfig(std::move(cfg)); }
    RepenteClient::Config const& Bridge::getConfig() const { return client.getConfig(); }
    bool Bridge::isBusy() const { return client.isBusy(); }

    void Bridge::send(juce::String const& prompt, std::function<void(bool)> onDone)
    {
        jassert(juce::MessageManager::getInstance()->isThisTheMessageThread());

        // Immediate user feedback
        if (editor && editor->pd)
            editor->pd->logMessage("repente: thinking...");

        client.send(prompt, [this, onDone](juce::String const& response) {
            // Already on message thread via callAsync in RepenteClient
            jassert(juce::MessageManager::getInstance()->isThisTheMessageThread());

            if (response.startsWith("error:")) {
                if (editor && editor->pd)
                    editor->pd->logMessage(response);
                if (onDone) onDone(false);
                return;
            }

            auto parsed = PdParser::parse(response);
            execute(parsed);
            if (onDone) onDone(true);
        });
    }

    void Bridge::execute(ParsedResponse const& parsed)
    {
        if (!editor) return;

        switch (parsed.type)
        {
            case ResponseType::PD_PATCH:
            {
                if (editor->pd) editor->pd->logMessage("repente: opening patch...");
                editor->getTabComponent().openPatch(parsed.content);
                break;
            }
            case ResponseType::LUA_BLOCK:
            {
                if (editor->pd) editor->pd->logMessage("repente: running Lua...");
                // Wrap in { } and route through PromptInput's Lua engine
                if (auto* pi = editor->getPromptInput())
                    pi->executeCommand(editor->pd, "{" + parsed.content + "}");
                break;
            }
            case ResponseType::PDS_COMMANDS:
            {
                if (editor->pd) editor->pd->logMessage("repente: executing commands...");
                // Execute each non-empty /pds line via PromptInput
                if (auto* pi = editor->getPromptInput()) {
                    for (auto const& line : juce::StringArray::fromLines(parsed.content)) {
                        auto trimmed = line.trim();
                        if (trimmed.isNotEmpty())
                            pi->executeCommand(editor->pd, trimmed);
                    }
                }
                break;
            }
        }
    }

    } // namespace RepentePd
    ```
