## Goal
Auto-detect Ollama (localhost:11434) or repente server (localhost:7860) on first launch when
no URL is configured. Warn users setting a remote URL that canvas data leaves their machine.
Update help text to surface Ollama as a supported backend.

## Purpose
V1.0 onboarding: users installing Ollama locally should get working config with zero manual setup.
Users pointing at cloud APIs should see a privacy nudge so they make an informed choice.

## Output
- First-launch auto-detect: ping localhost:11434 → 7860 → log instructions if neither found
- Privacy warning logged once whenever a non-localhost URL is set via `/config url`
- `/help llm` and `/config` help updated with Ollama guidance
</objective>

<task type="auto">
  <name>Task 1: First-launch Ollama auto-detect chain</name>
  <files>Source/PluginEditor.cpp</files>
  <action>
    After the config load block (line ~296), add auto-detect logic that fires only when
    `repente_url` was NOT in SettingsFile (first launch):

    ```cpp
    // Auto-detect on first launch
    if (!SettingsFile::getInstance()->hasProperty("repente_url")) {
        pd->logRepente("repente: no config — detecting LLM backend...");
        auto* sf = SettingsFile::getInstance();

        // Try Ollama first
        {
            RepentePd::RepenteClient::Config cfg;
            cfg.url   = "http://localhost:11434";
            cfg.model = "llama3.2";
            bridge->setConfig(cfg);
        }

        bridge->ping([this, sf](bool ok, juce::String const&) {
            if (ok) {
                sf->setProperty("repente_url",   juce::String("http://localhost:11434"));
                sf->setProperty("repente_model", juce::String("llama3.2"));
                sf->saveSettings();
                pd->logRepente("repente: Ollama detected at localhost:11434 (model: llama3.2)");
                pd->logMessage("  run: ollama list  — to see installed models\n"
                               "  use: /config model <name>  — to switch");
                return;
            }
            // Ollama not found — try repente server
            {
                RepentePd::RepenteClient::Config cfg;
                cfg.url   = "http://localhost:7860";
                cfg.model = "repente-1";
                bridge->setConfig(cfg);
            }
            bridge->ping([this, sf](bool ok2, juce::String const&) {
                if (ok2) {
                    sf->setProperty("repente_url",   juce::String("http://localhost:7860"));
                    sf->setProperty("repente_model", juce::String("repente-1"));
                    sf->saveSettings();
                    pd->logRepente("repente: server detected at localhost:7860");
                    return;
                }
                // Neither found
                pd->logRepente("repente: no LLM detected — configure with:");
                pd->logMessage(
                    "  Ollama (local):  /config url http://localhost:11434\n"
                    "  OpenAI:          /config url https://api.openai.com\n"
                    "                   /config key sk-...\n"
                    "                   /config model gpt-4o\n"
                    "  repente server:  /config url http://localhost:7860");
            });
        });
    }
    ```

    **Important:** The nested lambda captures `this` (PluginEditor*) and `bridge` via `this->bridge`.
    Ping timeout is 5s (hardcoded in RepenteClient). Both pings run sequentially via the chain.
    If `repente_url` IS already in SettingsFile (returning user), this entire block is skipped.

    **Do NOT change the existing config load block above** (lines 289-296) — that's for returning users.
