<objective>
## Goal
`/arrange` command that topology-sorts all canvas objects by signal-flow depth (sources
→ processors → sinks) and repositions them via `patch.moveObjectTo`, producing a readable
left-to-right patch layout.

## Purpose
After `/arrange`, a patch generated by the LLM (or assembled manually) becomes immediately
readable — sources on the left, audio sinks on the right, with clean column spacing.
Completes the auto-placement story from 05-01.

- `CommandType::PDS_ARRANGE` added to CommandParser

    ### ArrangeEngine.cpp

    Include: `"Utility/Config.h"`, `"ArrangeEngine.h"`, `"Canvas.h"`, `"Object.h"`, `"Connection.h"`.

    Implement `arrange(Canvas*)`:

    **Guard:** if `canvas == nullptr` or `canvas->objects.size() < 2`, return "arrange: nothing to arrange".

    **Step 1 — collect objects:**
    ```cpp
    std::vector<Object*> objs;
    for (auto* o : canvas->objects)
        if (o->getPointer() != nullptr) objs.push_back(o);
    if (objs.size() < 2) return "arrange: nothing to arrange";
    ```

    **Step 2 — build inbound-connection set:**
    ```cpp
    std::unordered_set<Object*> hasIncoming;
    for (auto* conn : canvas->connections) {
        if (conn->inobj != nullptr)
            hasIncoming.insert(conn->inobj.get());
    }
    ```

    **Step 3 — BFS to assign depth:**
    ```cpp
    std::unordered_map<Object*, int> depth;
    std::queue<Object*> q;
    for (auto* o : objs)
        if (hasIncoming.find(o) == hasIncoming.end()) {
            depth[o] = 0;
            q.push(o);
        }
    while (!q.empty()) {
        auto* cur = q.front(); q.pop();
        for (auto* conn : canvas->connections) {
            if (conn->outobj.get() != cur) continue;
            auto* dst = conn->inobj.get();
            if (dst == nullptr) continue;
            int d = depth[cur] + 1;
            if (depth.find(dst) == depth.end() || depth[dst] < d) {
                depth[dst] = d;
                q.push(dst);
            }
        }
    }
    ```
    Objects not reached (isolated, or in cycles): assign `max_depth + 1` after BFS.

    **Step 4 — assign isolated/unreached objects:**
    ```cpp
    int maxDepth = 0;
    for (auto& [o, d] : depth) maxDepth = std::max(maxDepth, d);
    for (auto* o : objs)
        if (depth.find(o) == depth.end())
            depth[o] = maxDepth + 1;
    ```

    **Step 5 — group by depth and position:**
    ```cpp
    std::map<int, std::vector<Object*>> layers;
    for (auto* o : objs) layers[depth[o]].push_back(o);

    constexpr int X_START = 60, X_STEP = 130;
    constexpr int Y_START = 60, Y_STEP = 70;

    if (auto patchPtr = canvas->patch.getPointer()) {
        canvas_dirty(patchPtr.get(), 1);
    }
    for (auto& [layer, layerObjs] : layers) {
        int x = X_START + layer * X_STEP;
        for (int i = 0; i < (int)layerObjs.size(); ++i) {
            int y = Y_START + i * Y_STEP;
            canvas->patch.moveObjectTo(layerObjs[i]->getPointer(), x, y);
        }
    }
    canvas->synchronise();
    ```

    Return `"arrange: " + juce::String(objs.size()) + " objects arranged in "
           + juce::String((int)layers.size()) + " columns"`.

    **Important:**
    - `canvas_dirty` is in pd namespace, accessed via `canvas->patch.getPointer()` then raw pd API —
      copy the exact pattern from `Canvas::alignObjects()` (Canvas.cpp:2217) to mark dirty + enable undo.
    - Do NOT call `patch.startUndoSequence` from ArrangeEngine — Executor will call if needed, or skip for now.
    - `PooledPtrArray<Connection>` iterates like a range-for — matches `canvas->objects` usage in Executor.
