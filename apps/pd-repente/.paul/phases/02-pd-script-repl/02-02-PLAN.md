<objective>
## Goal
Implement all five DirectCommands in Executor::execute() (create/connect/delete/move/list)
with real canvas mutations, and add a SugarExpander pre-processor ($last substitution +
→ arrow shorthand) that runs before CommandParser::parse().

## Purpose
Makes the REPL functional: user types /pds create osc~ and an object appears on canvas.
This satisfies the Phase 02 primary AC: "/pds create osc~ → object on canvas; audio thread unblocked."
Sugar makes multi-step patch building ergonomic without requiring full object names each time.

## Output
- Executor::execute() dispatches all five pd-script verbs to pd::Patch methods
- canvas->synchronise() called after each mutation so JUCE canvas reflects pd state
- SugarExpander.h/.cpp: stateless pre-processor, $last + → expansion
- PluginEditor.cpp: SugarExpander wired before CommandParser::parse()
</objective>

## AC-1: PDS_CREATE adds object to canvas
```gherkin
Given a canvas is open
When user types "/pds create osc~ 100 100" and presses Enter
Then an osc~ object appears on the canvas at position (100, 100)
And onResult returns "created obj_1" (or next name)
And the object is stored in the registry under "obj_1"
```

## AC-2: PDS_CONNECT wires two objects
```gherkin
Given obj_1 (osc~) and obj_2 (dac~) exist in the registry
When user types "/pds connect obj_1 obj_2 0 0" and presses Enter
Then a connection is created from obj_1 outlet 0 to obj_2 inlet 0
And onResult returns "connected obj_1:0 → obj_2:0"
```

## AC-3: PDS_DELETE, PDS_MOVE, PDS_LIST work correctly
```gherkin
Given obj_1 exists in registry
When user types "/pds delete obj_1"
Then object is removed from canvas and registry entry cleared

Given obj_1 exists
When user types "/pds move obj_1 200 200"
Then object position changes to (200, 200)

When user types "/pds list"
Then onResult returns all named objects and their pd-text
```

## AC-4: SugarExpander substitutes $last and expands → shorthand
```gherkin
Given last created object is "obj_1"
When user types "$last" anywhere in input
Then $last is replaced with "obj_1" before parse

Given last created is "obj_1"
When user types "→ dac~ 200 200"
Then expander rewrites to "/pds connect obj_1 NEW_NAME 0 0"
  where dac~ is created first at (200, 200)
```

Note: → shorthand means "create next object AND connect from $last to it".
Exact expansion: "→ name x y" → create name at x,y, then connect $last→new 0 0.
This requires two sequential pd operations — implement as two Executor calls or
handle as a special CommandType (PDS_ARROW) to keep Executor::execute() clean.

    ```cpp
    namespace RepentePd {

    // Stateless pre-processor: runs before CommandParser::parse().
    // Applies syntactic sugar that makes multi-step patch building ergonomic.
    class SugarExpander {
    public:
        // Expand sugar in `input` given `lastName` (last assignName() result).
        // Returns expanded string ready for CommandParser::parse().
        static juce::String expand(juce::String const& input,
                                   juce::String const& lastName);
    };

    } // namespace RepentePd
    ```

    Create `Source/RepentePd/Commands/SugarExpander.cpp`:

    Two expansion rules, applied in order:

    **Rule 1 — → shorthand:**
    If `trimmed` starts with `→` (U+2192) or `->`:
    - Strip the arrow prefix, trim remainder
    - Result is a new compound command — but CommandParser handles one command at a time.
    - For Phase 02-02: expand `→ rest` to `/pds create rest` (treat as create shorthand)
      AND store a pending-connect signal by appending `|connect:$last` as a suffix.
      Actually, this is complex for a single-pass expander.

    **Simpler → implementation for Phase 02-02:**
    Introduce `PDS_ARROW` CommandType (or handle in PluginEditor with two submits):
    - In PluginEditor onSubmit: detect if expanded text starts with `/pds create` AND
      lastName is non-empty — after submit, auto-submit a second command
      `/pds connect PREVIOUS_LAST NEW_OBJ 0 0`.
    - This is cleaner than compound CommandTypes.

    **Recommended approach (keep Executor simple):**
    In PluginEditor.cpp onSubmit lambda:
    ```cpp
    promptBar->onSubmit = [this](juce::String const& text) {
        juce::String lastName = executor->getLastCreatedName();
        juce::String expanded = RepentePd::SugarExpander::expand(text, lastName);

        // Arrow shorthand: "→ obj x y" → create obj, then connect lastName→new
        bool isArrow = RepentePd::SugarExpander::isArrow(text);
        juce::String preArrowLast = lastName; // capture before create changes it

        auto result = RepentePd::CommandParser::parse(expanded);
        executor->setCanvas(getCurrentCanvas());
        executor->submit(result, [this, isArrow, preArrowLast](juce::String const& msg) {
            fprintf(stderr, "RepentePd: %s\n", msg.toRawUTF8());
            if (isArrow && !preArrowLast.isEmpty()) {
                juce::String newName = executor->getLastCreatedName();
                if (newName.isNotEmpty() && newName != preArrowLast) {
                    auto connectResult = RepentePd::CommandParser::parse(
                        "/pds connect " + preArrowLast + " " + newName + " 0 0");
                    executor->submit(connectResult, [](juce::String const& m) {
                        fprintf(stderr, "RepentePd: %s\n", m.toRawUTF8());
                    });
                }
            }
        });
    };
    ```

    **SugarExpander::expand() — only $last substitution:**
    ```cpp
    juce::String SugarExpander::expand(juce::String const& input,
                                        juce::String const& lastName) {
        juce::String trimmed = input.trim();

        // Arrow: strip prefix, rewrite to /pds create
        if (trimmed.startsWith(juce::CharPointer_UTF8("\xe2\x86\x92"))  // →
            || trimmed.startsWith("->")) {
            int prefixLen = trimmed.startsWith("->") ? 2 : 3; // → is 3 UTF-8 bytes
            trimmed = "/pds create " + trimmed.substring(prefixLen).trim();
        }

        // $last substitution
        if (lastName.isNotEmpty())
            trimmed = trimmed.replace("$last", lastName);

        return trimmed;
    }
    ```

    **SugarExpander::isArrow() — static helper:**
    ```cpp
    bool SugarExpander::isArrow(juce::String const& input) {
        juce::String t = input.trim();
        return t.startsWith(juce::CharPointer_UTF8("\xe2\x86\x92")) || t.startsWith("->");
    }
    ```

    Add `isArrow` declaration to SugarExpander.h.

    In PluginEditor.cpp:
