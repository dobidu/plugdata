<objective>
## Goal
Build the REPL engine: CommandParser (tokenizer + /pds grammar) and Executor
(thread-safe canvas mutation dispatcher), wired end-to-end through PromptBar Enter key.

## Purpose
Establishes the two core invariants that all future phases depend on:
1. Every canvas mutation goes through Executor → MessageManager::callAsync (audio thread never touched)
2. Every user input goes through CommandParser before reaching Executor

## Output
- `CommandParser`: tokenizes `/pds <verb> [args]`, returns `CommandResult`
- `Executor`: receives `CommandResult`, dispatches via `callAsync`, holds object registry
- PromptBar Enter key fires the parser→executor pipeline (commands stub with DBG log)
</objective>

  <action>
    Define `CommandResult` struct and `CommandType` enum in CommandParser.h:

    ```cpp
    enum class CommandType { PDS_CREATE, PDS_CONNECT, PDS_DELETE, PDS_LIST,
                             PDS_MOVE, PDS_LUA, HELP, CLEAR, PASSTHROUGH, UNKNOWN };

    struct CommandResult {
        CommandType type = CommandType::UNKNOWN;
        juce::StringArray args;   // tokens after the verb
        juce::String error;       // non-empty = parse failed
        juce::String raw;         // original input
    };
    ```

    Implement `CommandParser` as a stateless class (all static methods):

    ```cpp
    class CommandParser {
    public:
        static CommandResult parse(juce::String const& input);
    private:
        static CommandResult parsePds(juce::StringArray const& tokens);
    };
    ```

    `parse()` logic:
    - Trim whitespace
    - If starts with "/pds ": call parsePds with remaining tokens
    - If "/help": return {HELP}
    - If "/clear": return {CLEAR}
    - If starts with "/": return {UNKNOWN, error="unknown command: <verb>"}
    - Otherwise: return {PASSTHROUGH, raw=input} — reserved for Phase 3 Repente bridge

    `parsePds()` maps first token to CommandType:
    create→PDS_CREATE, connect→PDS_CONNECT, delete→PDS_DELETE,
    list→PDS_LIST, move→PDS_MOVE, lua→PDS_LUA.
    Unknown verb → {UNKNOWN, error="unknown pd-script command: <verb>"}.
    Remaining tokens go into args.

    No sugar processing here — sugar pre-processor is Phase 02-02.
  </action>
  <verify>
    Add a JUCE UnitTest in Tests/RepentePdTests.h:
      parse("/pds create osc~ 100 100") → type==PDS_CREATE, args==["osc~","100","100"]
      parse("/pds foobar") → type==UNKNOWN, error non-empty
      parse("hello world") → type==PASSTHROUGH
    cmake --build + ctest passes.
  </verify>
  <done>AC-1 satisfied: CommandParser tokenizes all known verbs and returns correct CommandResult</done>

<task type="auto">

  <files>

  </files>
  <action>
    `Executor` holds a `juce::SafePointer<Canvas>` (not raw pointer — Canvas can be deleted
    when patch closes). Constructor takes `Canvas*`.

    ```cpp
    class Executor {
    public:
        explicit Executor(Canvas* canvas);

        // Thread-safe entry point. Safe to call from any thread.
        // onResult callback fires on message thread with human-readable result string.
        void submit(CommandResult const& cmd,
                    std::function<void(juce::String)> onResult = {});

        // Returns the auto-assigned name for the last created object, or "" if none.
        juce::String getLastCreatedName() const;

    private:
        void execute(CommandResult const& cmd,
                     std::function<void(juce::String)> onResult);

        juce::SafePointer<Canvas> canvas;

        // Object registry: name → t_gobj* (auto-assigned names: obj_1, obj_2, ...)
        // Guarded: only accessed on message thread.
        std::unordered_map<juce::String, t_gobj*> registry;
        int nextId = 1;

        juce::String assignName(t_gobj* obj);   // returns "obj_N", inserts into registry
        t_gobj* resolve(juce::String const& name);  // returns nullptr if not found

        JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR(Executor)
    };
    ```

    `submit()` implementation:
    ```cpp
    void Executor::submit(CommandResult const& cmd, std::function<void(String)> onResult) {
        MessageManager::callAsync([this, cmd, onResult] {
            execute(cmd, onResult);
        });
    }
    ```

    `execute()` body (Phase 02-01 — stubs only, DirectCommands added in 02-02):
    ```cpp
    void Executor::execute(CommandResult const& cmd, std::function<void(String)> onResult) {
        JUCE_ASSERT_MESSAGE_THREAD
        if (!canvas) { if (onResult) onResult("error: canvas closed"); return; }

        DBG("Executor::execute " + String(magic_enum::enum_name(cmd.type)) + " "
            + cmd.args.joinIntoString(" "));

        // Stub: real dispatch added in 02-02
        String result = "not implemented: " + cmd.raw;
        if (onResult) onResult(result);
    }
    ```

    Note: avoid magic_enum if not available — use a local typeToString() helper instead.
    Note: JUCE_ASSERT_MESSAGE_THREAD is a JUCE macro (juce_events). Include juce_events.h or
    use jassert(MessageManager::getInstance()->isThisTheMessageThread()).
  </action>
