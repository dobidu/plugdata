
    Create AudioCapture with this interface and implementation:

    **AudioCapture.h:**
    ```cpp
    class AudioCapture {
    public:
        // Message thread: arm capture for durationSec seconds at sampleRate.
        // Resets any prior capture. Safe to call while processBlock runs.
        void startCapture(float durationSec, int sampleRate, int numChannels);

        // Audio thread (processBlock): feed output samples. Wait-free.
        // Ignores feed if not capturing or already ready.
        void feedAudio(juce::AudioBuffer<float> const& buffer);

        // Message thread: true once enough samples accumulated.
        [[nodiscard]] bool isReady() const;
        // Message thread: true while capture in progress (armed but not yet ready).
        [[nodiscard]] bool isCapturing() const;

        // Message thread: move captured buffer out. Resets to idle.
        // Returns empty buffer if not ready.
        [[nodiscard]] juce::AudioBuffer<float> takeCapture();

    private:
        juce::AudioBuffer<float> captureBuffer;
        std::atomic<int>  writePos   { 0 };
        std::atomic<int>  targetSamples { 0 };
        std::atomic<bool> armed      { false };
        std::atomic<bool> ready_     { false };
        int               channels_  { 0 };
    };
    ```

    **AudioCapture.cpp — startCapture:**
    - Set armed=false (pause audio thread writes momentarily via ready_ guard)
    - Compute targetSamples = ceil(durationSec * sampleRate)
    - Resize captureBuffer to (numChannels, targetSamples), clear it
    - Reset writePos=0, ready_=false
    - Set armed=true last (memory_order_release) → audio thread starts writing

    **feedAudio (audio thread, wait-free):**
    ```
    if (!armed.load(memory_order_acquire) || ready_.load(memory_order_acquire)) return;
    int pos = writePos.load(memory_order_relaxed);
    int target = targetSamples.load(memory_order_relaxed);
    int toCopy = jmin(buffer.getNumSamples(), target - pos);
    if (toCopy <= 0) return;
    for each channel: captureBuffer.copyFrom(ch, pos, buffer, ch % channels_, 0, toCopy);
    int newPos = pos + toCopy;
    writePos.store(newPos, memory_order_release);
    if (newPos >= target) { armed.store(false, memory_order_release); ready_.store(true, memory_order_release); }
    ```

    **isReady / isCapturing:**
    - isReady() = ready_.load(relaxed)
    - isCapturing() = armed.load(relaxed) && !ready_.load(relaxed)

    **takeCapture:**
    - if (!ready_) return empty AudioBuffer
    - Move captureBuffer into local result (std::move)
    - Reset: ready_=false, armed=false, writePos=0, targetSamples=0
    - Return result

    Avoid: mutexes in feedAudio (audio thread constraint). Avoid: blocking audio thread.
    Include: `<atomic>`, `<juce_audio_basics/juce_audio_basics.h>`
  </action>
