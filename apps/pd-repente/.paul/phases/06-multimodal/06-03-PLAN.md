<objective>
## Goal
Wire AudioCapture + SpectralAnalyzer into the LLM request pipeline and expose
`/listen [prompt]` as a user-facing command.

`/listen` captures 3 seconds of audio output, runs spectral analysis, injects the
result into the next LLM request as additional system context, then sends the prompt.

## Purpose
Completes the C3 Tríade multimodal loop:
  generate → play → /listen → capture → analyze → inject → LLM refine

    ```cpp
    if (msg.startsWith("/listen")) {
        if (!bridge) {
            pdInstance->logRepente("repente: bridge not ready -- use /config url to set server");
            return {};
        }
        juce::String prompt = msg.substring(7).trim();
        if (prompt.isEmpty())
            prompt = "I just heard the audio output. What do you observe and suggest?";

        if (!pluginEditor || !pluginEditor->pd) return {};
        pluginEditor->pd->startAudioCapture(3.0f);
        pdInstance->logRepente("repente: listening (3s)...");

        // Capture bridge + pd pointers for the lambda (both outlive the delay).
        auto* br = bridge;
        auto* pd = pluginEditor->pd;

        juce::MessageManager::callAfterDelay(3200, [br, pd, prompt] {
            auto buffer   = pd->audioCapture.takeCapture();
            int const sr  = static_cast<int>(pd->getSampleRate());
            auto result   = RepentePd::SpectralAnalyzer::analyze(buffer, sr > 0 ? sr : 44100);
            auto spectral = RepentePd::SpectralAnalyzer::format(result);
            pd->logRepente("repente: analyzing audio...");
            br->send(prompt, /*analyzeOnly=*/false, {}, spectral);
        });
        return {};
    }
    ```
