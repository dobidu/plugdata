<objective>
## Goal
Add `/analyze <question>` command: sends current canvas + question to LLM, displays
response as plain text in console — no patch execution, no PdParser routing.

## Purpose
Free-text prompts currently expect the LLM to respond with executable pd/Lua/pds content.
Analysis mode lets the user ask questions about the patch ("what does this do?",
"why is it clipping?", "suggest improvements") and get a readable answer without
accidentally executing LLM output as patch commands.

## Output
- `Bridge::send()` gains an `analyzeOnly` flag that bypasses PdParser
- `/analyze <question>` command in PromptInput routes to analyze mode
- `/help llm` updated with `/analyze` usage
</objective>

    In `Bridge::send()`, change the response callback to branch on `analyzeOnly`:

    ```cpp
    bool Bridge::send(juce::String const& prompt, bool analyzeOnly, std::function<void(bool)> onDone)
    {
        jassert(juce::MessageManager::getInstance()->isThisTheMessageThread());

        juce::String context;
        if (auto* canvas = editor ? editor->getCurrentCanvas() : nullptr)
            context = CanvasSerializer::serialize(canvas);

        if (editor && editor->pd)
            editor->pd->logMessage(analyzeOnly ? "repente: analyzing..." : "repente: thinking...");

        return client.send(prompt, context, [this, analyzeOnly, onDone](juce::String const& response) {
            jassert(juce::MessageManager::getInstance()->isThisTheMessageThread());

            if (response.startsWith("error:")) {
                if (editor && editor->pd)
                    editor->pd->logMessage(response);
                if (onDone) onDone(false);
                return;
            }

            if (analyzeOnly) {
                if (editor && editor->pd)
                    editor->pd->logMessage(response);
                if (onDone) onDone(true);
                return;
            }

            auto parsed = PdParser::parse(response);
            execute(parsed);
            if (onDone) onDone(true);
        });
    }
    ```

    **Avoid:** Changing the call sites in PromptInput that use `bridge->send(msg)` —
    default `analyzeOnly = false` means existing free-text behavior is unchanged.
