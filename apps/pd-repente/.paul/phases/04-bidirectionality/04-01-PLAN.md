<objective>
## Goal
Serialize the active canvas to pd-file format and inject it as a system message into every
LLM request, giving the model full patch context for context-aware generation.

## Purpose
Without canvas context, the LLM writes blind — it cannot add to, modify, or reason about
the existing patch. Phase 04 is defined by bidirectionality: the canvas state flows into
the prompt. This plan is the foundational piece everything else in Phase 04 builds on.

## Output
- `CanvasSerializer`: static `serialize(Canvas*)` → pd-file-format string
- `RepenteClient::send()` gains a `systemContext` parameter (injected as `role: system`)
- `Bridge::send()` calls serializer, passes context to client on every prompt
- `/canvas` command in PromptInput shows serialized context in console (debug)
</objective>

    ```cpp
    #pragma once
    #include <juce_core/juce_core.h>
    class Canvas;

    namespace RepentePd {

    class CanvasSerializer {
    public:
        // Serialize active canvas to pd-file format.
        // Returns empty string if canvas is null or has no objects.
        // Must be called from the message thread.
        static juce::String serialize(Canvas* canvas);
    };

    } // namespace RepentePd
    ```

    ### CanvasSerializer.cpp

    ```cpp
    #include "Utility/Config.h"
    #include "CanvasSerializer.h"
    #include "Canvas.h"
    #include "Connection.h"
    #include "Object.h"
    #include "Pd/Interface.h"
    #include <unordered_map>

    namespace RepentePd {

    juce::String CanvasSerializer::serialize(Canvas* canvas)
    {
        if (!canvas || canvas->objects.isEmpty()) return {};

        juce::String result;
        result += "#N canvas 0 0 800 600 10;\n";

        // Build index map: Object* → int index
        std::unordered_map<Object*, int> indexMap;
        for (int i = 0; i < canvas->objects.size(); ++i)
            indexMap[canvas->objects[i]] = i;

        // Emit objects
        for (auto* obj : canvas->objects) {
            auto bounds = obj->getObjectBounds();
            juce::String text;
            if (auto* ptr = obj->getPointer())
                text = pd::Interface::getObjectText((t_object*)ptr);
            if (text.isEmpty())
                text = obj->getType();
            result += "#X obj " + juce::String(bounds.getX())
                    + " " + juce::String(bounds.getY())
                    + " " + text + ";\n";
        }

        // Emit connections
        for (auto* conn : canvas->connections) {
            if (!conn->outobj || !conn->inobj) continue;
            auto srcIt = indexMap.find(conn->outobj.get());
            auto dstIt = indexMap.find(conn->inobj.get());
            if (srcIt == indexMap.end() || dstIt == indexMap.end()) continue;
            result += "#X connect " + juce::String(srcIt->second)
                    + " " + juce::String(conn->outIdx)
                    + " " + juce::String(dstIt->second)
                    + " " + juce::String(conn->inIdx) + ";\n";
        }

        return result;
    }

    } // namespace RepentePd
    ```

    **Avoid:** Including Canvas.h or Connection.h in the .h file — keep those in .cpp only
    to limit compile-time includes. The Canvas* forward decl in .h is sufficient.

    **Note:** `getObjectText()` takes `t_object const*` but `getPointer()` returns `t_gobj*`.
    The cast `(t_object*)` is the standard pd pattern — all canvas objects are t_objects at the
    C level. Guard against null pointer before casting.
