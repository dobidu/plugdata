<objective>
## Goal
Add multi-turn conversation history to the LLM bridge — each request includes prior
exchanges so the model remembers what was said — and persist history across restarts
via SettingsFile. Add `/history` and `/history clear` commands.

## Purpose
Currently every LLM request is stateless: the model sees canvas context and one user
message, with no memory of prior turns. Multi-turn lets the user build iteratively
("make it louder", "now add reverb", "why is it clipping?") without re-explaining
context each time. Persistence means the session survives an accidental restart.

## Output
- `RepenteClient::send()` accepts a messages array instead of prompt+systemContext
- `Bridge` maintains `conversationHistory` (capped at 20 exchanges)
- History serialized to/from SettingsFile as JSON; cleared via `/history clear`
- `/history` shows turn count; `/history clear` wipes and confirms
</objective>

    ```cpp
    struct HistoryMessage { juce::String role; juce::String content; };
    static constexpr int MAX_HISTORY_TURNS = 20; // 20 user + 20 assistant = 40 msgs

    void clearHistory();
    [[nodiscard]] int historyTurnCount() const;  // user-message count

    private:
    std::vector<HistoryMessage> conversationHistory;
    void saveHistory() const;
    void loadHistory();
    static juce::String serializeHistory(std::vector<HistoryMessage> const&);
    static std::vector<HistoryMessage> deserializeHistory(juce::String const&);
    ```

    ### Bridge.cpp — update send() to build messages array

    In `Bridge::send()`, build the full `RepenteClient::Message` vector:

    ```cpp
    // Always inject fresh canvas snapshot as system message
    std::vector<RepenteClient::Message> messages;
    if (context.isNotEmpty())
        messages.push_back({"system", context});

    // Inject conversation history (prior turns)
    for (auto const& m : conversationHistory)
        messages.push_back({m.role, m.content});

    // Append current user prompt
    messages.push_back({"user", prompt});

    return client.send(messages, [this, analyzeOnly, prompt, onDone]
                       (juce::String const& response) {
        // ... existing error/analyzeOnly handling unchanged ...

        if (!analyzeOnly) {
            // Append to history only on successful non-analyze turns
            conversationHistory.push_back({"user",      prompt});
            conversationHistory.push_back({"assistant", response});

            // Trim to cap: keep last MAX_HISTORY_TURNS*2 messages
            while (static_cast<int>(conversationHistory.size()) > MAX_HISTORY_TURNS * 2)
                conversationHistory.erase(conversationHistory.begin());

            saveHistory();
        }
        // ... rest of existing execute/onDone logic ...
    });
    ```

    ### Bridge.cpp — clearHistory / save / load / serialize

    ```cpp
    void Bridge::clearHistory() {
        conversationHistory.clear();
        SettingsFile::getInstance()->setProperty("repente_history", juce::String(""));
        SettingsFile::getInstance()->saveSettings();
    }

    int Bridge::historyTurnCount() const {
        // Count user messages only
        return static_cast<int>(std::count_if(conversationHistory.begin(),
            conversationHistory.end(),
            [](HistoryMessage const& m) { return m.role == "user"; }));
    }

    void Bridge::saveHistory() const {
        auto str = serializeHistory(conversationHistory);
        SettingsFile::getInstance()->setProperty("repente_history", str);
        SettingsFile::getInstance()->saveSettings();
    }

    void Bridge::loadHistory() {
        auto str = SettingsFile::getInstance()->getProperty<juce::String>("repente_history");
        if (str.isNotEmpty())
            conversationHistory = deserializeHistory(str);
    }
    ```

    Serialization: use nlohmann/json (already vendored). Each HistoryMessage serializes as
